Đây là bài viết đầu tiên trên blog. Mình sẽ dùng nơi này để đăng các bài phân tích **reverse engineering**, **malware analysis**, và các writeup CTF.

## Cách viết bài mới

Mỗi bài viết là một file Markdown trong thư mục `_posts/`, đặt tên theo định dạng:

```
YYYY-MM-DD-ten-bai-viet.md
```

Với front matter ở đầu file:

```yaml
---
title: "Tiêu đề bài viết"
categories: [reverse-engineering]
tags: [windows, x86, ida-pro]
---
```

Sau đó viết nội dung bằng Markdown bên dưới — hỗ trợ code block có syntax highlighting, ảnh, bảng, v.v. Xem bài mẫu ["Phân tích một crackme đơn giản"]({{ "/reverse-engineering/2026/09/11/phan-tich-crackme-mau/" | relative_url }}) để tham khảo cấu trúc một bài RE writeup.
